# Sana — математика каждый день

Установочное веб-приложение для индивидуальных занятий математикой. Механика вдохновлена современными образовательными тренажёрами: **диагностика → персональная программа → короткий урок каждый день**. Название, интерфейс и все задания собственные. Куратор и чат не нужны.

## Что работает

- **Диагностика из 8 вопросов** по шести темам. По результатам вычисляется карта знаний и автоматически выбираются три приоритетные темы.
- **Ежедневный персональный план**: шесть заданий, подсказки, мгновенная проверка и объяснение решения.
- **6 курсов**: вычисления, дроби, уравнения, геометрия, проценты и текстовые задачи.
- **Тематические тесты** с сохранением лучшего результата.
- **Собственный банк из 38 заданий**, включая вопросы с выбором ответа и ручным вводом числа или дроби.
- **Прогресс и мотивация**: XP, уровни, серия занятий, недельная цель, график активности, уровни навыков и достижения.
- **Профиль ученика**: имя, класс, ежедневная цель и напоминания.
- **PWA**: установка на телефон или компьютер, отдельная иконка и офлайн-кэш.
- **Адаптивный интерфейс** и отдельный фокус-режим во время занятия.
- **Автономная Android-оболочка** на WebView.

Прогресс хранится локально в `localStorage`. Регистрация, сервер и интернет для прохождения уроков не требуются. В текущей версии нет синхронизации между устройствами.

## Запуск

Нужен Node.js 20+ для проверок и сборки; само приложение не требует фреймворка или production-зависимостей.

```bash
npm start
# http://localhost:8080
```

Подойдёт и любой другой статический HTTP-сервер. Для установки как PWA нужен HTTP(S), а не `file://`.

## Проверки

```bash
npm ci
npm test
```

Тесты покрывают:

- вычисление результатов диагностики и выбор слабых тем;
- проверку чисел и эквивалентных дробей;
- полный UI-сценарий «диагностика → программа → ежедневный урок → результат»;
- фильтры курсов и сохранение профиля;
- сборку и запуск автономного HTML без внешних JS/CSS-файлов.

## Сборка

```bash
npm run build          # release/Sana.html + свежая версия sw.js
npm run icons          # иконки PWA
npm run android:icons  # иконки Android
```

`release/Sana.html` — самодостаточная версия со встроенными стилями и скриптами. Её можно открыть без сервера.

## Android

APK использует автономный HTML из `release/Sana.html`.

```bash
npm ci
npm run build
cd android
gradle assembleRelease -PversionCode=1 -PversionName=1.0.0
# → android/app/build/outputs/apk/release/Sana.apk
```

Сборка также настраивается в `.github/workflows/android.yml`. Подробнее — [`android/README.md`](android/README.md).

## Структура

```text
index.html                 — оболочка приложения и навигация
styles.css                 — дизайн и адаптивная вёрстка
src/
  app.js                   — экраны, маршруты и взаимодействия
  data.js                  — курсы, задания и начальные демо-данные
  learning.js              — диагностика, проверка ответов и персональный план
  icons.js                 — SVG-иконки интерфейса
scripts/                   — сборка, иконки и автоматические проверки
tests/learning.test.js     — модульные тесты обучающей логики
manifest.webmanifest, sw.js — PWA и офлайн-режим
android/                   — Android-оболочка
```
